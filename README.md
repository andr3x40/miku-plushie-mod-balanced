# Hey! This is a fork of another mod!
This is a project of mine to balance the [Miku Plushies](https://github.com/4nyNoob/miku-plushie-mod) mod made by 4ny and SuoYukii to better fit a Vanilla-like environment.

This was done only for Project Twilight Duck (temporary modpack name), a semi-vanilla modpack made for a community private server.

Go support the original creators of this mod!

## Differences with the original mod
Here are all the differences with the original [Miku Plushies](https://github.com/4nyNoob/miku-plushie-mod) mod.

### Mechanics
- Vocaloid Heart is non-stackable and is consumed on use
- When attacking, pets move 1.2x faster instead of 1.5x
- Pets' weapons are damaged on attack

### Item Changes
- Neru's phone now requires a Tinted Glass instead of a Black Stained Glass (she needs privacy, y'know)
- Teto Pickaxe has a durability of 401 instead of 500 (objectively a better number)

## Compatibility Notes
This mod works for **Fabric 1.21.1**.

To use this on **NeoForge 1.21.1**, you'll need these mods:
- [Forgified Fabric API](https://github.com/Sinytra/ForgifiedFabricAPI)
- [Sinytra Connector](https://github.com/Sinytra/Connector)
- [Sinytra Connector Extras](https://github.com/Sinytra/ConnectorExtras)
